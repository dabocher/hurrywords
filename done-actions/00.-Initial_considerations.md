# Consideraciones Iniciales — Importación del Diccionario

## Fecha
Septiembre 2026

## Resumen

Al importar el diccionario completo desde `data/words.jsonl` a la base de datos de Convex (tabla `rae_words`), es **obligatorio** ejecutar la función de patch para poblar los campos de índice.

## Procedimiento

1. **Importar el diccionario:**
   ```
   npx convex import data/words.jsonl rae_words
   ```

2. **Ejecutar el patch de indexación:**
   ```
   npx convex run patch:addRandomFields
   ```

   Este mutation popula los campos `firstLetter` y `randomOrder` en todos los documentos de `rae_words`. Se ejecuta en rondas de 1000 palabras y se auto-reschedula hasta completar el 100%.

## ¿Por qué es necesario?

La tabla `rae_words` utiliza dos índices que dependen de estos campos:

- `by_letter_random` → usa `firstLetter` + `randomOrder`
- `by_random` → usa `randomOrder`

Ambos campos son `v.optional()` en el schema, lo que significa que las palabras importadas **no vienen con estos campos poblados**. Sin ellos, las queries que usan estos índices retornan 0 resultados, causando que:

- El cronjob `generateDailyPalabrejas` cree un registro `palabrejas_daily` con `validWords: []` (vacío)
- Los demás cronjobs que dependen de `rae_words` no encuentren palabras

## Verificación

Para confirmar que el patch se completó, ejecutar de nuevo:

```
npx convex run patch:addRandomFields
```

La respuesta esperada es:
```
¡ÉXITO TOTAL! Ya no quedan palabras sin parchear. El diccionario está al 100%.
```

Si dice `Se parchearon X palabras...`, ejecutar el comando nuevamente hasta que complete.
