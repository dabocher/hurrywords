## 1. Timer — Nueva funcionalidad

### Comportamiento
- El timer de **60 segundos** arranca cuando el usuario introduce la **primera letra válida** (no al cargar la página).
- Corre continuamente, sin pausas (incluyendo durante verificaciones de palabras).
- Se **persiste en localStorage**: si el usuario recarga la página, el tiempo restante se mantiene.
- Al expirar: se bloquean las letras y el input, y aparece un overlay de "fin del tiempo".

## 4. Bug Fix

### Timer no persiste al recargar cuando expiró
**Problema:** Cuando el timer llegaba a 0 y el usuario recargaba la página, el timer se reseteaba a 60s en vez de mantenerse en expired.

**Causa:** El useEffect de persistencia en `use-timer.ts` solo guardaba en localStorage cuando `status === "running"` o `status === "idle"`. Nunca guardaba cuando el timer alcanzaba `expired`.

**Solución:** Agregada condición en `use-timer.ts:58-60`:
```ts
if (status === "expired" && startedAtRef.current) {
  saveTimerState(date, startedAtRef.current, duration);
}
```
